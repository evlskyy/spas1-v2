SPAS1 Version 2.1.1

Aplikasi operasional MBG untuk SPPG Sungai Pasir 1 Meral, Karimun, dengan Supabase sebagai backend dan Cloudflare Pages untuk publikasi frontend.

Tentang Project

SPAS1 Version 2.1.1 membantu mengelola menu, stok logistik, absensi relawan, persiapan, distribusi, dan informasi SPPG. Alur backend telah bermigrasi dari Apps Script dan Spreadsheet ke Supabase.

Supabase menjadi backend aplikasi untuk autentikasi, PostgreSQL, kebijakan akses, dan penyimpanan media. Tombol Sinkronisasi Database dan Tarik dari Database menggunakan adapter Supabase pada modul yang terhubung, mengikuti sesi login dan kebijakan akses tiap tabel.

Cloudflare Pages menyajikan frontend statis. Kode sumber dapat dikelola di GitHub dan diterbitkan melalui integrasi deployment yang dikonfigurasi untuk repository tersebut. Cloudflare Workers hanya digunakan untuk fungsi edge bila memang dikonfigurasi; Worker bukan pengganti database Supabase.

  • Sinkronisasi Modul 4: joblist, resep, anggaran, HACCP, jadwal distribusi, target porsi, poster AKG, dan snapshot operasional terhubung ke tabel Supabase masing-masing.
  • Kontrol data: akses baca/tulis mengikuti sesi login dan Row Level Security (RLS). Data kredensial tidak disalin ke sinkronisasi frontend; pengelolaan akun menggunakan Supabase Auth.

Pembaruan Versi 2.0 ke 2.1.1 · TERUPDATE

Alur backend aplikasi beralih dari Apps Script dan Spreadsheet ke Supabase untuk autentikasi, database, sinkronisasi, dan media. Frontend statis dipublikasikan melalui Cloudflare Pages; deployment mengikuti konfigurasi repository GitHub.

  • Info SPPG di halaman depan: admin dapat menerbitkan informasi dapur, lowongan kerja, dan pengumuman yang dapat dibaca pengguna.
  • Poster dan foto: mendukung poster lowongan, AKG, menu MBG harian, serta foto lampiran pengumuman. File dan metadata dikelola melalui Supabase Storage dan database.
  • Pengaturan identitas oleh SUPER ADMIN: pengelola dapat mengubah nama yayasan, nama SPPG, dan logo global untuk identitas lintas halaman. Logo khusus modul tetap dapat digunakan.
  • Halaman Tentang Kami: admin dapat mengatur total dan rincian penerima manfaat, jumlah relawan, struktur jabatan, tugas, nama, serta foto. Nama/foto personel dipublikasikan dengan persetujuan dan dikelola melalui Supabase.
  • Kontrol admin: pengelolaan info, media, dan identitas dibatasi untuk sesi admin; tombol logout tersedia di sidebar dan disesuaikan untuk desktop maupun ponsel.
  • Perbaikan tema: pilihan tema light/dark dan tema Modul 4 diselaraskan, termasuk tampilan SUPER ADMIN LOGIN.
  • Penyempurnaan proses login: autentikasi menggunakan Supabase Auth; kecepatan login dapat dipengaruhi koneksi internet dan waktu respons layanan.
  • Penyempurnaan lintas perangkat: panel info, form admin, dan navigasi dibuat responsif agar tetap nyaman digunakan di layar desktop maupun ponsel.
  • Identitas dan dukungan: tombol Trakteer ditambahkan pada halaman utama dan READ INFO PROJECT.
  • Menu SUPER AKSES dan Akuntan: Konten & Tautan Situs, Laporan, Relawan, dan Registrasi dikelompokkan di SUPER AKSES. Menu Akuntan memiliki submenu Audit & Riwayat Transaksi Stok, Stok & Nota, Folder LPDH & LPJ, LPDH Harian, dan LPJ.
  • SUPER GIZI — Kalkulator AKG: hitung otomatis zat gizi per porsi dari gramasi dan data per 100 g yang dimasukkan. Ringkasan visual menampilkan donat kontribusi energi, kartu makronutrien, batang capaian target, dan tiga kontribusi tertinggi. Data tersimpan di browser perangkat ini, serta dapat diekspor ke CSV atau dicetak.
  • Audit dan pencatatan stok: admin dapat meninjau riwayat stok masuk/keluar dan mengelola Stok & Nota untuk pencatatan pembelian, penggunaan, bukti foto timemark, serta lokasi.
  • LPDH Harian: pencatatan porsi penerima manfaat, belanja pangan beserta bukti nota, biaya operasional dapur, saldo awal/akhir dan top-up kas. Tersedia ekspor Excel, CSV, PDF, cetak, serta kolom tanda tangan visual Kepala SPPG dan Akuntan.
  • LPJ Administrasi SPPG: delapan lembar kerja yang dapat diisi dan diedit, disimpan per tanggal di Supabase, serta diekspor ke Excel atau PDF/cetak. Nama bawaan disamarkan sebagai Anonymous dan dapat diedit; tanda tangan visual tersedia untuk lembar pengesahan.
  • Folder LPDH & LPJ: arsip laporan harian dikelompokkan menurut tanggal, membuka isi folder untuk memilih LPDH/LPJ, lalu memuat laporan tersimpan beserta bukti nota LPDH.
  • Perbaikan cetak laporan: LPJ dicetak dalam A4 landscape beberapa halaman tanpa memotong isi lembar, sedangkan Audit Stok memakai A4 landscape dengan latar putih dan tanpa overlay aplikasi.
  • Registrasi relawan satu tahap persetujuan: pendaftar mengisi nama, ID Relawan, email, nomor HP, dan PIN. Setelah satu kali disetujui SUPER ADMIN, akun langsung aktif pada database relawan; PIN disimpan sebagai hash, bukan teks biasa.
  • Antrean registrasi admin: permohonan disimpan pada tabel database terpisah, tampil di menu Registrasi SUPER ADMIN dengan badge jumlah menunggu, dan mendukung keputusan setujui/tolak.
  • Perbaikan layar login Absensi: latar blur dipertahankan, sementara form registrasi yang lebih tinggi dari viewport dapat digulir sampai tombol aksi.
  • Pembaruan Pagu Anggaran PO: kebutuhan matang dihitung dari gramasi tiap porsi besar/kecil dikali jumlah porsi; kebutuhan bahan mentah dikali FK. Biaya dikonversi ke satuan harga yang sejenis. Harga atau satuan yang tidak cocok ditandai dan tidak dimasukkan diam-diam ke total.
  • Pembaruan LPDH: total tiap baris adalah volume dikali harga satuan, dibulatkan ke Rupiah. Total pengeluaran, saldo tersedia (saldo awal + top-up), saldo akhir, rincian kategori, dan pemakaian plafon operasional diperbarui otomatis.
  • Pembaruan LPJ: saldo BKU berjalan dihitung dari penerimaan dikurangi pengeluaran. Realisasi anggaran mengikuti kategori akun pengeluaran; sisa dan persentase serapan dihitung terhadap pagu. Kartu stok, total pangan, distribusi porsi, dan insentif juga memiliki perhitungan otomatis.
  • Pembaruan Kalkulator AKG: zat gizi per porsi dihitung dari nilai per 100 g dikali gramasi dibagi 100. Total dan persentase terhadap target hanya ditampilkan jika target AKG lebih dari nol.

Pendaftaran tidak mengirim OTP. Email yang dimasukkan belum otomatis diverifikasi; SUPER ADMIN perlu memeriksa permohonan secara manual sebelum menyetujui. Registrasi dan data operasional tersimpan melalui Supabase. Foto publik dapat dilihat oleh siapa pun yang memiliki tautannya.

Tutorial Penggunaan Aplikasi

Panduan langkah demi langkah untuk menggunakan SPAS1 Version 2.1.1. Menu dan tindakan yang tersedia dapat berbeda sesuai akun, hak akses, serta konfigurasi ke Database.

1. Mulai menggunakan aplikasi

  1. Buka aplikasi melalui browser yang terhubung ke internet. Gunakan tombol Kembali ke Menu Utama bila sedang berada di halaman lain.
  2. Pilih kartu modul pada halaman utama: Absensi PIN, Bank Menu & Gizi, Stok Logistik, atau Persiapan & Distribusi.
  3. Halaman publik seperti Read Info Project, Tentang Kami, dan Radar Info Terbaru dapat dibuka tanpa masuk ke portal admin.
  4. Untuk mengelola data, gunakan akun dengan peran yang telah diberikan. Jika diminta login, masukkan kredensial portal yang benar; jangan membagikan kata sandi atau PIN.

2. Modul Absensi Relawan ( HAK AKSES TERBATAS )

  1. Relawan baru: pilih Registrasi, isi nama lengkap, ID Relawan, email aktif, nomor HP, role/divisi, lalu buat dan ulangi PIN minimal 8 karakter. Selesaikan verifikasi keamanan dan kirim formulir.
  2. Tunggu pemeriksaan dan persetujuan SUPER ADMIN. Email tidak diverifikasi dengan OTP secara otomatis; pastikan data yang dimasukkan benar.
  3. Login: masukkan ID Relawan dan PIN, lalu tekan Verifikasi & Masuk.
  4. Pilih Absen Masuk, Istirahat, Selesai Istirahat, atau Absen Pulang sesuai kegiatan. Ikuti petunjuk pemindaian dan lokasi, pilih/ambil foto bila diminta, lalu tekan Catat Kehadiran dengan PIN.
  5. Periksa pesan hasil pencatatan. Setelah selesai, tekan Keluar. Jika kamera atau GPS tidak tersedia, izinkan akses browser bila diperlukan atau gunakan pilihan foto yang tersedia.

Animasi/pemindaian visual bukan pencocokan wajah atau verifikasi identitas. GPS bergantung pada izin browser dan ketersediaan perangkat.

3. Modul Bank Menu & Gizi ( HAK AKSES TERBATAS )

  1. Masuk dengan akun portal Bank Menu yang berwenang. Jika belum login, masukkan username dan kata sandi portal pada layar masuk.
  2. Gunakan kolom pencarian, filter Hari, dan Kategori untuk menemukan menu. Buka kartu menu untuk melihat komposisi serta informasi gizi.
  3. Untuk mengatur menu kalender, pilih kategori, bulan, hari, minggu, dan menu master, lalu tekan Tambahkan ke Periode. Gunakan Muat Ulang Jadwal untuk mengambil ulang jadwal dari database.
  4. Pengguna yang berwenang dapat menambah atau mengedit menu master dan komposisi bahan/gizi. Setelah perubahan, tekan Sync Database; gunakan Tarik dari Database untuk memuat data yang tersimpan.
  5. Gunakan Print atau Export PDF untuk mencetak/menyimpan daftar menu.

4. Modul Stok Logistik ( HAK AKSES TERBATAS )

  1. Pilih hari kerja pada tab hari di bagian atas. Daftar belanja menunjukkan transaksi pembelian untuk hari yang dipilih; gunakan pencarian untuk menemukan bahan tertentu.
  2. Pilih Belanja Harian untuk melihat pembelian, atau Pemakaian Koki untuk mencatat pemakaian utama dan pecahan. Sisa dihitung setara otomatis; SUPER ADMIN dapat mengembalikan seluruh sisa yang tercatat ke stok gudang sebagai transaksi masuk.
  3. Untuk mencatat pembelian atau stok keluar gudang, petugas berwenang membuka SUPER ADMIN → Akuntan → Stok & Nota. Pilih tindakan yang sesuai, masukkan bahan/jumlah dan catatan yang diminta, isi lokasi, lampirkan foto nota/bukti, lalu tekan Simpan Transaksi.
  4. Foto nota/bukti wajib untuk transaksi Stok & Nota. Lokasi GPS opsional; jika GPS tidak tersedia, isi lokasi secara manual. Catat beberapa bahan dari satu nota dalam satu transaksi. Transaksi uji nyata memengaruhi stok; gunakan Batalkan Nota dari Audit untuk membalikkan stok, bukan menghapus riwayat.
  5. Gunakan Muat Ulang untuk mengambil data terbaru. Pemakaian koki mengurangi sisa di dapur dan tidak menambah stok gudang.

5. Modul Persiapan & Distribusi ( HAK AKSES TERBATAS )

  1. Masuk menggunakan akun Persiapan/Distribusi atau admin yang berwenang. Navigasi modul berada di bagian atas: Dashboard & Joblist, Standar Resep, PO Belanja Harian, dan Poster Menu AKG.
  2. Di Dashboard, pilih hari untuk melihat menu dan jadwal. Gunakan Ubah Target Porsi untuk mengatur porsi besar/kecil serta total target, dan Jadwal Distribusi untuk mengatur waktu distribusi.
  3. Kelola tugas melalui Tambah Tugas, filter hari/status, pencarian, atau impor teks. Perbarui status tugas saat pekerjaan dimulai atau selesai. Backup/restore JSON tersedia untuk pemulihan data lokal.
  4. Di Standar Resep, pilih hari untuk melihat panduan resep. Di PO Belanja Harian, pilih hari dan tekan Hitung dari Menu Harian untuk menghitung kebutuhan serta estimasi anggaran; tinjau bahan, porsi, stok, dan harga sebelum mencetak.
  5. Di Poster Menu AKG, pengguna berwenang dapat mengunggah dan mengelola poster. Gunakan Sinkronisasi Database untuk menyimpan/memuat data operasional sesuai hak akses.
  6. Isi checklist HACCP sesuai pemeriksaan aktual: suhu penyimpanan, uji organoleptik, sanitasi, dan label batas konsumsi. Gunakan warna talenan sesuai bahan makanan yang tercantum di layar.

6. SUPER ADMIN dan SUPER AKSES ( HAK AKSES TERBATAS )

  1. Dari halaman utama pilih SUPER ADMIN, masukkan kredensial admin, lalu tekan tombol login. Setelah berhasil, menu admin muncul di sidebar. Tekan Logout Admin setelah selesai.
  2. Pengaturan memuat pengelolaan identitas aplikasi, Tentang Kami, dan Info SPPG. Simpan perubahan dengan tombol aksi pada halaman terkait.
  3. SUPER AKSES → Konten & Tautan Situs: ubah teks Tentang Kami/Read Info Project, tautan media sosial, dan tombol WhatsApp; simpan konten situs setelah mengedit.
  4. SUPER AKSES → Laporan: pilih/sinkronkan data absensi, lalu gunakan ekspor PDF/CSV atau Print. Relawan untuk meninjau/mengelola akun; Registrasi untuk memeriksa permohonan baru dan menyetujui atau menolaknya.
  5. SUPER GIZI → Kalkulator AKG: isi nama/kategori bahan, berat bahan dalam satu porsi, serta data gizi per 100 g dari sumber yang sudah diverifikasi. Kalkulator memperbarui donat energi, kartu makronutrien, batang capaian target, dan tiga kontribusi tertinggi secara otomatis. Isi target AKG yang sesuai penerima; target energi awal 2.150 kkal hanya ilustrasi dari contoh. Data tersimpan lokal di browser yang sama, dapat diekspor sebagai CSV atau dicetak.
  6. Perubahan hanya dapat dilakukan sesuai hak admin. Periksa kembali data sebelum menyimpan atau memublikasikan, terutama nama/foto personel dan informasi yang dilihat publik.

7. Menu Akuntan: Audit, Stok & Nota, LPDH, dan LPJ ( HAK AKSES TERBATAS )

  1. Audit & Riwayat Transaksi Stok: pilih tanggal audit lalu tekan Tampilkan untuk memuat transaksi yang tersimpan pada hari tersebut.
  2. Stok & Nota: pilih input nota/stok masuk atau catat stok keluar gudang. Lengkapi barang, jumlah, pemasok/catatan, lokasi, dan foto bukti yang diwajibkan sebelum menyimpan. Riwayat transaksi dan pembatalan tersedia di Audit sesuai izin.
  3. LPDH Harian: pilih tanggal dan tekan Muat Laporan. Isi identitas SPPG/periode, porsi penerima manfaat, saldo awal, top-up, serta plafon operasional jika berlaku. Tambahkan rincian transaksi, pilih kategori, isi uraian/volume/harga/pemasok, dan lampirkan nota.
  4. Tinjau ringkasan total biaya, dana tersedia, pengeluaran, saldo kas akhir, dan status plafon. Isi nama Kepala SPPG/Akuntan; tanda tangan dapat digambar pada area tanda tangan. Tekan Simpan LPDH sebelum ekspor.
  5. LPJ: pilih tanggal laporan agar data tanggal tersebut dimuat, lengkapi identitas, lalu isi delapan lembar: identitas, Buku Kas Umum, LRA, biaya bahan pangan, kartu stok, BAST distribusi, rekap hadir/insentif, serta SPTJM/pemeriksaan kas.
  6. Tambahkan baris sesuai kebutuhan, tinjau perhitungan otomatis, edit nama bawaan Anonymous bila diperlukan, lalu gambar tanda tangan pihak terkait. Tekan Simpan LPJ; ekspor memakai Excel 8 Lembar atau PDF / Print.
  7. Buka Akuntan → Folder LPDH & LPJ untuk melihat arsip per tanggal. Klik folder kuning untuk memilih laporan LPDH atau LPJ, lalu pilih laporan yang ingin dibuka. Folder diperbarui otomatis setelah laporan berhasil disimpan.

Tanda tangan di LPDH/LPJ adalah gambar tanda tangan untuk dokumen, bukan tanda tangan elektronik tersertifikasi. Gunakan tanggal laporan yang benar dan pastikan skema Supabase/migrasi fitur sudah diterapkan sebelum menyimpan data.

8. Ekspor, cetak, dan pemecahan masalah

  1. Tombol PDF biasanya membuka dialog cetak browser. Pilih Save as PDF jika ingin menyimpan berkas, atau pilih printer untuk mencetak.
  2. Untuk laporan lebar seperti LPJ dan Audit Stok, biarkan ukuran/orientasi halaman mengikuti pengaturan cetak aplikasi (A4 landscape). Periksa pratinjau, margin, dan tujuan cetak sebelum menyimpan.
  3. Jika data belum muncul, pastikan tanggal benar, tekan tombol muat ulang, periksa koneksi internet dan status login, lalu coba lagi. Jangan mengirim laporan berulang kali ketika proses simpan masih berjalan.
  4. Jika unggahan nota, sinkronisasi, atau penyimpanan gagal, periksa koneksi dan izin akses akun. Hubungi admin bila pesan gagal berulang; jangan membagikan kata sandi, PIN, token login, atau tautan bukti pribadi.

Masukkan berat bahan per porsi dan nilai zat gizi pada setiap 100 g bahan.

Catatan acuan: sistem menghitung otomatis dari angka yang dimasukkan, tetapi tidak memiliki basis data komposisi pangan bawaan. Gunakan sumber yang sudah diverifikasi ahli gizi. Nilai energi awal 2.150 kkal mengikuti contoh yang diberikan dan hanya ilustrasi; sesuaikan target untuk kelompok penerima. Persentase adalah kontribusi menu per porsi terhadap target yang diisi, bukan klaim kecukupan harian.
