SPAS1 Version 2.0

Aplikasi web komprehensif untuk mendukung pengelolaan operasional harian dapur Makan Bergizi Gratis (MBG) untuk SPPG Sungai Pasir 1, Meral, Karimun.

Tentang Proyek

Aplikasi berbasis web yang dapat digunakan melalui URL Google Apps Script tanpa membeli domain sendiri. SPAS1 Version 2.0 membantu mengelola 500+ paket menu, stok logistik, dan absensi relawan dengan sinkronisasi data melalui layanan Google.

Google Apps Script digunakan sebagai backend untuk mengotomatisasi proses dan menghubungkan aplikasi dengan Google Sheets sebagai penyimpanan data operasional. Platform ini juga dapat dimanfaatkan untuk membangun berbagai solusi, seperti aplikasi inventaris, keuangan, belanja, maupun portofolio.

Keamanan: Saya menggunakan serverless Blind XSS Hunter oleh @IAmMandatory sebagai backbone security untuk menghindari Mitigasi Resiko dari Cyber Attack.

Arsitektur Sistem

  • FrontendHTML, Tailwind CSS, dan JavaScript (single-page application).
  • BackendGoogle Apps Script, termasuk doGet, doPost, dan fungsi aplikasi.
  • DatabaseGoogle Sheets dengan beberapa sheet terstruktur.
  • HostingGoogle Apps Script Web App, diakses melalui URL deployment.

Modul yang Dibangun

  • Modul 1 · Absensi Relawan: pencatatan berbasis PIN, laporan lokasi dari browser, dan pemindaian visual.
  • Modul 2 · Bank Menu & Gizi: lebih dari 500 paket menu standar MBG dan pengelolaan informasi gizi.
  • Modul 3 · Stok Logistik: pengelolaan lebih dari 600 item bahan baku dan bumbu.
  • Modul 4 · Persiapan & Distribusi: joblist harian, jadwal distribusi, dan checklist HACCP.

Keunggulan Apps Script

  • Dapat dimulai tanpa server dan domain sendiri; penggunaan mengikuti kuota serta kebijakan layanan Google.
  • Terintegrasi dengan Google Sheets untuk pengelolaan data.
  • Dapat diakses melalui URL dari perangkat yang terhubung ke internet.
  • Mendukung sinkronisasi data antarperangkat.
  • Praktis dikelola tanpa infrastruktur Development yang kompleks.

Project ini membuktikan bahwa solusi teknologi tidak harus mahal, dapat dibangun secara bertahap dengan pemahaman yang tepat,memanfaatkan Google Apps Script sebagai backbone aplikasi operasional skala menengah.

Fitur & fungsi

  • Pengelolaan menu harian MBG dan bank menu berisi 500+ paket.
  • Pengelolaan 600+ data stok logistik dapur.
  • Pencatatan absensi harian relawan berbasis PIN.
  • Monitoring operasional, pelaporan, dan dokumentasi.
  • Sinkronisasi data melalui layanan cloud.

Pemindaian visual pada absensi bukan verifikasi identitas.
