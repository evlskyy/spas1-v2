SPAS1 Version 2.1.1

Aplikasi operasional MBG untuk SPPG Sungai Pasir 1 Meral, Karimun, dengan Supabase sebagai backend dan Cloudflare Pages untuk publikasi frontend.

Tentang Project

SPAS1 Version 2.1.1 membantu mengelola menu, stok logistik, absensi relawan, persiapan, distribusi, dan informasi SPPG. Alur backend telah bermigrasi dari Apps Script dan Spreadsheet ke Supabase.

Supabase menjadi backend aplikasi untuk autentikasi, PostgreSQL, kebijakan akses, dan penyimpanan media. Tombol Sinkronisasi Database dan Tarik dari Database menggunakan adapter Supabase pada modul yang terhubung, mengikuti sesi login dan kebijakan akses tiap tabel.

Cloudflare Pages menyajikan frontend statis. Kode sumber dapat dikelola di GitHub dan diterbitkan melalui integrasi deployment yang dikonfigurasi untuk repository tersebut. Cloudflare Workers hanya digunakan untuk fungsi edge bila memang dikonfigurasi; Worker bukan pengganti database Supabase.

  • Sinkronisasi Modul 4: joblist, resep, anggaran, HACCP, jadwal distribusi, target porsi, poster AKG, dan snapshot operasional terhubung ke tabel Supabase masing-masing.
  • Kontrol data: akses baca/tulis mengikuti sesi login dan Row Level Security (RLS). Data kredensial tidak disalin ke sinkronisasi frontend; pengelolaan akun menggunakan Supabase Auth.

Pembaruan Versi 2.0 ke 2.1.1 · TERUPDATE

Alur backend aplikasi beralih dari Apps Script dan Spreadsheet ke Supabase untuk autentikasi, database, sinkronisasi, dan media. Frontend statis dipublikasikan melalui Cloudflare Pages; deployment mengikuti konfigurasi repository GitHub.

  • Info SPPG di halaman depan: admin dapat menerbitkan informasi dapur, lowongan kerja, dan pengumuman yang dapat dibaca pengguna.
  • Poster dan foto: mendukung poster lowongan, AKG, menu MBG harian, serta foto lampiran pengumuman. File dan metadata dikelola melalui Supabase Storage dan database.
  • Pengaturan identitas oleh SUPER ADMIN: pengelola dapat mengubah nama yayasan, nama SPPG, dan logo global untuk identitas lintas halaman. Logo khusus modul tetap dapat digunakan.
  • Halaman Tentang Kami: admin dapat mengatur total dan rincian penerima manfaat, jumlah relawan, struktur jabatan, tugas, nama, serta foto. Nama/foto personel dipublikasikan dengan persetujuan dan dikelola melalui Supabase.
  • Kontrol admin: pengelolaan info, media, dan identitas dibatasi untuk sesi admin; tombol logout tersedia di sidebar dan disesuaikan untuk desktop maupun ponsel.
  • Perbaikan tema: pilihan tema light/dark dan tema Modul 4 diselaraskan, termasuk tampilan SUPER ADMIN LOGIN.
  • Penyempurnaan proses login: autentikasi menggunakan Supabase Auth; kecepatan login dapat dipengaruhi koneksi internet dan waktu respons layanan.
  • Penyempurnaan lintas perangkat: panel info, form admin, dan navigasi dibuat responsif agar tetap nyaman digunakan di layar desktop maupun ponsel.
  • Identitas dan dukungan: tombol Trakteer ditambahkan pada halaman utama dan READ INFO PROJECT.
  • Registrasi relawan satu tahap persetujuan: pendaftar mengisi nama, ID Relawan, email, nomor HP, dan PIN. Setelah satu kali disetujui SUPER ADMIN, akun langsung aktif pada database relawan; PIN disimpan sebagai hash, bukan teks biasa.
  • Antrean registrasi admin: permohonan disimpan pada tabel database terpisah, tampil di menu Registrasi SUPER ADMIN dengan badge jumlah menunggu, dan mendukung keputusan setujui/tolak.
  • Perbaikan layar login Absensi: latar blur dipertahankan, sementara form registrasi yang lebih tinggi dari viewport dapat digulir sampai tombol aksi.

Pendaftaran tidak mengirim OTP. Email yang dimasukkan belum otomatis diverifikasi; SUPER ADMIN perlu memeriksa permohonan secara manual sebelum menyetujui. Registrasi dan data operasional tersimpan melalui Supabase. Foto publik dapat dilihat oleh siapa pun yang memiliki tautannya.

Visi, Misi & Identitas Visual SPAS1

Visi SPAS1: menjadi sarana digital yang tertata, mudah diakses, dan dapat diandalkan untuk membantu tim SPPG Sungai Pasir 1 menjalankan layanan operasional MBG dengan lebih terkoordinasi.

Misi SPAS1: menyatukan pencatatan absensi relawan, pengelolaan menu dan gizi, pemantauan logistik, serta persiapan dan distribusi dalam satu aplikasi; menyediakan informasi yang mudah dikelola; dan membantu admin menjaga data operasional tetap terstruktur.

  • Bentuk gelembung percakapan: melambangkan komunikasi dan koordinasi antara relawan, pengelola, dan tim operasional.
  • Huruf S putih: inisial SPAS1—Sungai Pasir 1—sebagai penanda identitas aplikasi yang sederhana dan mudah dikenali.
  • Warna toska: secara visual memberi kesan segar, sehat, dan bertumbuh, selaras dengan layanan pangan dan gizi.
  • Warna putih pada huruf S: memberi kontras yang jelas di atas latar toska dan menyimbolkan keterbukaan serta kejelasan informasi.

Rumusan visi, misi, dan makna warna di atas menjelaskan arah serta identitas aplikasi SPAS1; bukan pengganti visi-misi resmi Yayasan Bidadari Indonesia Gemilang.

Arsitektur Sistem

  • FrontendHTML, Tailwind CSS, dan JavaScript (single-page application).
  • Backend dan autentikasiSupabase Auth dan REST API.
  • Database dan Penyimpanan MediaSupabase PostgreSQL dengan Row Level Security (RLS) serta Supabase Storage untuk file media aplikasi.
  • KeamananServerless Blind XSS digunakan sebagai komponen pendukung pemantauan keamanan aplikasi web.

Modul yang Dibangun

  • Modul 1 · Absensi Relawan: pencatatan berbasis PIN, laporan lokasi dari browser, dan pemindaian visual.
  • Modul 2 · Bank Menu & Gizi: lebih dari 500 paket menu standar MBG dan pengelolaan informasi gizi.
  • Modul 3 · Stok Logistik: pengelolaan lebih dari 600 item bahan baku dan bumbu.
  • Modul 4 · Persiapan & Distribusi: joblist harian, jadwal distribusi, dan checklist HACCP.

Keunggulan Supabase

  • Menyediakan autentikasi, database PostgreSQL, dan penyimpanan media untuk kebutuhan aplikasi.
  • Terintegrasi dengan Supabase untuk autentikasi, data operasional, dan media.
  • Dapat diakses melalui URL dari perangkat yang terhubung ke internet.
  • Mendukung sinkronisasi data antarperangkat.
  • Praktis dikelola tanpa infrastruktur Development yang kompleks.

Project ini membuktikan bahwa solusi teknologi dapat dibangun secara bertahap dengan pemahaman yang tepat, memanfaatkan Supabase sebagai backend aplikasi operasional.

Fitur & fungsi

  • Pengelolaan menu harian MBG dan bank menu berisi 500+ paket.
  • Pengelolaan 600+ data stok logistik dapur.
  • Pencatatan absensi harian relawan berbasis PIN.
  • Monitoring operasional, pelaporan, dan dokumentasi.
  • Sinkronisasi data melalui layanan cloud.
