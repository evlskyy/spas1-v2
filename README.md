# SPAS1 Version 2.0

Aplikasi web komprehensif untuk mengelola operasional dapur MBG di SPPG Sungai Pasir 1 Meral, Karimun.

## 📋 Tentang Project

SPAS1 (Sungai Pasir 1) adalah aplikasi web yang saya bangun untuk membantu pengelolaan operasional harian dapur MBG (Makan Bergizi Gratis).

## 🚀 Fitur & Fungsi

- Pengelolaan menu harian MBG
- Absensi Harian Relawan ( Face ID Recognition )
- 500+ Paket Bank Menu
- 600+ Stok Logistik Dapur
- Monitoring operasional dapur
- Pelaporan dan dokumentasi
- Sinkronisasi Cloud
